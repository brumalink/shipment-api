# Security policy

## Reporting a vulnerability

Please **do not** open a public issue. E-mail security@brumalink.example with a description.
We acknowledge reports within 2 business days.

## Supported platform versions

| Version | Supported |
|---|---|
| 2.x | ✅ |
| 1.x | security fixes until 2026-12-31 |
| < 1.0 | ❌ |

## Scope

- Shipment Platform API
- Tracker payload signing (see [docs/ingestion.md](docs/ingestion.md))
