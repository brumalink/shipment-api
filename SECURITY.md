# Security policy

## Reporting a vulnerability

Please **do not** open a public issue. E-mail security@brumalink.example with a description and, if possible,
steps to reproduce. We acknowledge reports within 2 business days.

## Supported versions

| Version | Supported |
|---|---|
| 2.x | ✅ |
| 1.x | security fixes until 2026-12-31 |
| < 1.0 | ❌ |

## Scope

- This API and its container image
- Tracker payload signing (`X-Tracker-Signature`)

Out of scope: tracker firmware (report to the firmware team via the same address).
